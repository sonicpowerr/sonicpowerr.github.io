# SONIC POWER X1 — Gaming 3D Website
1. Keep `models/headphone.glb` in the models folder.
2. Open the project folder in VS Code.
3. Use Live Server on index.html.
4. The site includes a 3D GLB viewer, Buy Now, Cart, gaming specs, radar HUD and responsive layout.
5. Connect the Buy Now / Checkout buttons to your actual payment backend before accepting payments.
